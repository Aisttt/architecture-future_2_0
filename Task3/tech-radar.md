## Обоснование ключевых изменений

### Внедрение (ADOPT)

1. **Apache Kafka** - критически важна для event-driven архитектуры и развязки доменов
2. **ClickHouse** - решает проблему производительности аналитических запросов
3. **Apache Superset** - обеспечивает требуемый self-service BI
4. **Kubernetes/Docker** - необходимы для масштабирования и независимого развертывания доменов
5. **PostgreSQL** - надежная OLTP база с открытым кодом для доменов

### Отказ (HOLD)

1. **Microsoft SQL Server 2008** - критически устаревшая версия с рисками безопасности
2. **Power Builder** - отсутствие специалистов, ограниченные возможности
3. **Apache Camel** - замена на более современные решения (Kafka, API Gateway)

### Пилоты (TRIAL)

1. **Event Sourcing/CQRS** - для финансового домена где важна аудируемость
2. **Data Mesh** - для масштабирования аналитики при росте доменов
3. **MLflow** - стандартизация ML процессов
